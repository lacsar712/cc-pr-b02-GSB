# 印刷套准复核台

接口只把印张偏差放进待处理队列。另一个进程用行锁领走一条，算出套准或套不准后再写回。页面每隔一秒看一次，直到结论出现。

机台带暂停闸：印刷员对某机台点暂停后，领取进程跳过该机台名下的待处理，其它机台照常；恢复后继续领取。暂停与恢复都写入闸门流水。菜单里的「机台暂停闸」页含机台状态、一键暂停/恢复与闸门流水。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3194 |
| 接口 | http://localhost:8194 |
| PostgreSQL | localhost:54394 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| printer | print123456 | 可送复核、可开关机台闸门 |
| checker | check123456 | 只看任务、闸门与流水 |

## 启动

```bash
cd projects/15-print-register-review
docker compose up --build
```

## 验收

1. printer 登录后稍等，封面-01（甲机）变成套准，内页-09（乙机）变成套不准。
2. 再送一条青偏差 0.5 的印张，状态先是待处理，随后变成套不准。
3. 菜单打开「机台暂停闸」，对甲机点暂停：甲机新任务保持待处理不被领走，乙机新任务照常先被领走出结论；再对甲机点恢复，甲机任务随后才被领走。暂停与恢复都出现在闸门流水里。
4. checker 没有送复核按钮，也没有暂停/恢复按钮，只能查看机台状态与闸门流水。
