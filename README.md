# 印刷套准复核台

接口只把印张偏差放进待处理队列。另一个进程用行锁领走一条，算出套准或套不准后再写回。页面每隔一秒看一次，直到结论出现。

## 机台闸门

每条复核任务都挂在机台名下。印刷员在「机台闸门」页对某机台点暂停后，领取进程跳过该机台名下的待处理，其它机台照常领取；点恢复后该机台任务继续被领。暂停与恢复都会写入闸门流水，页面上同时展示机台状态与流水。只读账号只能查看机台状态与闸门流水，不能操作闸门。

## 端口

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| printer | print123456 | 可送复核、可开关机台闸门 |
| checker | check123456 | 只看队列、机台状态与闸门流水 |

## 启动

```bash
cd projects/15-print-register-review
docker compose up --build
```

## 验收

1. printer 登录后稍等，封面-01 变成套准，内页-09 变成套不准。
2. 再送一条青偏差 0.5 的印张，状态先是待处理，随后变成套不准。
3. checker 没有送复核按钮，机台闸门页只能查看不能点暂停或恢复。
4. 甲机有任务待处理时，在机台闸门页点暂停甲机；再送一条乙机任务，乙机任务先被领走出结论，甲机任务仍是待处理；恢复甲机后，甲机任务才被领走，且闸门流水里能看到暂停与恢复两条记录。
